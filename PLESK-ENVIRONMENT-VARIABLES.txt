------------------------------------------------------------------------------
  REQUIRED — the application will not start, or will lose data, without these
------------------------------------------------------------------------------

  Set these first. Everything else is optional.

  DATA_DIR
      Absolute path, OUTSIDE the deployment directory, where user accounts, the credential vault, the
      audit log and the event history live. Production refuses to start without it rather than guess at
      somewhere a deploy would wipe. Example: /var/www/vhosts/supportwizard.net/netkit-data

  SESSION_SECRET
      At least 32 random characters. Signs sessions AND is the key the credential vault is encrypted
      with, so it CANNOT be stored in the vault. If this changes, every credential saved in the portal
      becomes unreadable and has to be entered again. Generate with: openssl rand -base64 48

  NODE_ENV
      Set to: production. Turns on secure cookies and the stricter defaults.
      Default: development


------------------------------------------------------------------------------
  STRONGLY RECOMMENDED
------------------------------------------------------------------------------

  PUBLIC_URL
      The address the portal is reached on, e.g. https://comms.supportwizard.net — used to build the
      links to events that go on helpdesk tickets. Without it, tickets say the event exists but cannot
      link to it. Settable in the portal instead.

  PORT
      Only if Passenger does not set it. Default 3000.
      Default: 3000

  PUBLIC_DIR
      Where the built front end is. Leave unset unless the layout is non-standard.


------------------------------------------------------------------------------
  FIRST RUN ONLY — delete these lines once the admin account exists
------------------------------------------------------------------------------

  Read only when the very first administrator is created. What is stored is a scrypt hash, never the
  password, so leaving the plain password here afterwards is a risk for no benefit.

  ADMIN_EMAIL
      The first administrator. Defaults to joe@supportwizard.net.

  ADMIN_PASSWORD
      The first administrator’s password. If unset, a strong one is generated and printed to the
      application log once, and must be changed at first sign-in.

  ADMIN_NAME
      Display name for the first administrator.

  BEHAVIOUR — all have sensible defaults. Set only to change them
------------------------------------------------------------------------------

  ZEN_ALLOW_ORDERING
      true to permit real orders. Off by default, and the portal has a second switch that must also be
      on — two independent locks, because ordering spends money.
      Default: false

  SUPERVISOR_ENABLED
      true by default. The five-minute health sweep and the outage watcher ride this.
      Default: true

  SUPERVISOR_INTERVAL_SECONDS
      Default 300. The outage check paces itself to five minutes regardless.
      Default: 300

  SUPERVISOR_ESCALATE_AFTER_MINUTES

      Default: 60

  SELFTEST_ON_BOOT

      Default: true
